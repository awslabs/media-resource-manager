


## Detailed Workflow

### Phase 1: Research

The agent queries Amazon Bedrock (Claude) with context about the software:

```
Prompt: "I need to create a silent installation script for {software_name} version {version}.
The installer is located at {media_url}.
Platform: {platform}

Research and provide:
1. Silent install command-line flags
2. Required prerequisites (runtimes, dependencies)
3. Common installation issues and solutions
4. Post-installation verification steps
5. Any licensing considerations for unattended install"
```

**Output:** Structured research findings including:
- Silent install parameters
- Prerequisites list
- Known issues
- Verification commands

### Phase 2: Script Generation

Based on research, generate platform-specific script:

**Windows (PowerShell):**
```powershell
# Auto-generated installation script for {software_name}
# Generated by AI Agent on {timestamp}

$ErrorActionPreference = "Stop"
$installerPath = "{media_url}"
$logPath = "C:\Windows\Temp\{software_name}_install.log"

# Prerequisites
Write-Host "Installing prerequisites..."
# {prerequisite_commands}

# Download installer if S3 URL
if ($installerPath -like "s3://*") {
    $localPath = "C:\Windows\Temp\installer.exe"
    aws s3 cp $installerPath $localPath
    $installerPath = $localPath
}

# Install
Write-Host "Installing {software_name}..."
$process = Start-Process -FilePath $installerPath -ArgumentList "{silent_flags}" -Wait -PassThru
if ($process.ExitCode -ne 0) {
    throw "Installation failed with exit code: $($process.ExitCode)"
}

# Verify
Write-Host "Verifying installation..."
# {verification_commands}

Write-Host "Installation completed successfully"
```

**Linux (Bash):**
```bash
#!/bin/bash
# Auto-generated installation script for {software_name}
# Generated by AI Agent on {timestamp}

set -e

INSTALLER_PATH="{media_url}"
LOG_PATH="/var/log/{software_name}_install.log"

# Prerequisites
echo "Installing prerequisites..."
# {prerequisite_commands}

# Download installer if S3 URL
if [[ "$INSTALLER_PATH" == s3://* ]]; then
    LOCAL_PATH="/tmp/installer"
    aws s3 cp "$INSTALLER_PATH" "$LOCAL_PATH"
    chmod +x "$LOCAL_PATH"
    INSTALLER_PATH="$LOCAL_PATH"
fi

# Install
echo "Installing {software_name}..."
{install_command}

# Verify
echo "Verifying installation..."
# {verification_commands}

echo "Installation completed successfully"
```

### Phase 4: Script Execution & Validation

Execute the generated script via SSM:

```javascript
// Lambda: execute-test-script
const command = await ssm.sendCommand({
  InstanceIds: [instanceId],
  DocumentName: platform === 'windows' 
    ? 'AWS-RunPowerShellScript' 
    : 'AWS-RunShellScript',
  Parameters: {
    commands: [generatedScript],
    executionTimeout: ['900'] // 15 minutes
  }
});

// Wait for completion and check results
const result = await waitForCommand(command.CommandId, instanceId);

if (result.Status === 'Success') {
  // Run verification commands
  const verification = await runVerification(instanceId, verificationCommands);
  return { success: verification.passed, logs: result.Output };
} else {
  return { success: false, error: result.StandardErrorContent };
}
```

### Phase 5: Iteration Loop

If the script fails, the agent analyzes the error and generates a revised script:

```
Prompt: "The installation script failed with the following error:
{error_output}

Previous script:
{previous_script}

Analyze the error and generate a corrected script that addresses:
1. The specific error encountered
2. Any missing prerequisites
3. Alternative installation approaches if needed

Attempt {attempt_number} of {max_attempts}."
```

**Iteration limits:**
- Maximum 3 attempts per software
- 15-minute timeout per attempt
- Total workflow timeout: 60 minutes

## Challenges and Mitigations

### 1. Cost Control

**Challenge:** Test instances and Bedrock API calls can accumulate costs.

**Mitigations:**
- Use `t3.medium` instances (cheapest with adequate resources)
- Hard limit of 3 test attempts per software
- Auto-terminate instances after 30 minutes maximum
- EventBridge rule to clean up orphaned test instances
- Monthly budget alerts for agent usage
- Admin-configurable daily/monthly limits

**Estimated Cost per Script Generation:**
| Component | Cost |
|-----------|------|
| Bedrock Claude (research + iterations) | ~$0.10-0.50 |
| EC2 t3.medium (30 min max × 3 attempts) | ~$0.06 |
| SSM commands | Negligible |
| **Total per script** | **~$0.20-0.60** |

### 2. Security

**Challenge:** Running arbitrary scripts on EC2 instances poses security risks.

**Mitigations:**
- Test instances in isolated subnet (no internet egress except S3/SSM)
- Dedicated security group with minimal permissions
- IAM role with only required permissions (S3 read, SSM)
- No access to production resources
- Scripts sanitized before execution (no shell injection)
- All generated scripts logged for audit
- Test instances have no access to customer data

**Security Group Rules:**
```
Inbound: None (SSM uses VPC endpoints)
Outbound: 
  - 443 to S3 VPC endpoint (installer download)
  - 443 to SSM VPC endpoints (command execution)
  - 443 to Secrets Manager (if license keys needed)
```

### 3. Licensing

**Challenge:** Some software requires license acceptance or keys during silent install.

**Mitigations:**
- Prompt user for license key if required
- Store license keys in Secrets Manager (encrypted)
- Agent includes license acceptance flags when detected
- Document licensing requirements in software entry
- Support for license server URLs

**License Key Handling:**
```javascript
// Store securely
await secretsmanager.createSecret({
  Name: `/${pascalCaseName}/Software/${softwareId}/LicenseKey`,
  SecretString: licenseKey,
  KmsKeyId: dataEncryptionKeyId
});

// Reference in script (not embedded)
// PowerShell:
$licenseKey = (Get-SECSecretValue -SecretId "..." -Select SecretString)
```

### 4. Verification

**Challenge:** How do we know the software actually installed correctly?

**Mitigations:**
- Agent generates verification commands based on software type:
  - Check for installed programs (registry/package manager)
  - Verify executable exists and runs
  - Check service status if applicable
  - Validate version number
- Screenshot capability for GUI applications (future)
- Exit code validation

**Verification Examples:**
```powershell
# Windows - Check registry
$installed = Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\*" | 
    Where-Object { $_.DisplayName -like "*Photoshop*" }
if (-not $installed) { throw "Software not found in registry" }

# Windows - Check executable
if (-not (Test-Path "C:\Program Files\Adobe\Photoshop\Photoshop.exe")) {
    throw "Executable not found"
}

# Linux - Check package
if ! dpkg -l | grep -q "software-name"; then
    echo "Package not installed" && exit 1
fi
```

### 5. Time Constraints

**Challenge:** Some installers take a long time (30+ minutes).

**Mitigations:**
- Configurable timeout per software (default 15 min, max 60 min)
- Progress streaming via SSE to frontend
- Background processing with status polling
- User notification when complete
- Ability to cancel long-running tests

### 6. Platform Differences

**Challenge:** Same software may install differently on Windows Server vs Windows 10, or Ubuntu vs RHEL.

**Mitigations:**
- Test on the same base AMI used for workstations
- Platform-specific script templates
- Agent aware of OS differences
- Option to test on multiple platforms
- Document tested platforms in software entry

## API Design

```
POST /images/software/{softwareId}/generate-script

Request:
{
  "testAutomatically": true,
  "maxAttempts": 3,
  "timeoutMinutes": 30,
  "licenseKey": "XXXX-XXXX-XXXX" // optional
}

Response:
{
  "executionId": "exec-abc123",
  "status": "in_progress",
  "progressUrl": "/images/software/{softwareId}/generation-progress"
}
```

```
GET /images/software/{softwareId}/generation-progress?executionId=exec-abc123

## Example Agent Prompts

### Research Prompt
```
You are an expert in software deployment and silent installations. 

I need to create an unattended installation script for:
- Software: {name}
- Version: {version}
- Platform: {platform}
- Installer type: {exe|msi|dmg|deb|rpm}
- Installer location: {s3_url}

Please research and provide:

1. **Silent Install Command**
   - The exact command-line flags for silent/unattended installation
   - Any required parameters (install directory, features, etc.)

2. **Prerequisites**
   - Required runtimes (.NET, VC++, Java, etc.)
   - System requirements
   - Commands to install prerequisites silently

3. **Known Issues**
   - Common installation failures and solutions
   - Compatibility issues with Windows Server / headless Linux

4. **Verification**
   - How to verify successful installation
   - Registry keys, file paths, or commands to check

5. **Licensing**
   - Does this software require license acceptance during install?
   - How to provide license key silently?

Format your response as structured JSON.
```

The installation script failed. Please analyze the error and provide a corrected script.

**Software:** {name} {version}

**Attempt:** {attempt} of {max_attempts}

```
